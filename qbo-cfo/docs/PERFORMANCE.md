# Performance

Generated by `npm run benchmark`. Every figure is a measured wall-clock time,
not an estimate.

## Method

A throwaway company is built with 24 months of derived metrics and the stated
number of transactions, each carrying one to three line items, spread across ten
vendors and three locations. The transactions are synthetic but shaped like real
ones, because the cost lives in the joins and the aggregation rather than in the
row count alone.

Chat timings are the deterministic resolution only. When `OPENAI_API_KEY` is set,
add the model latency: the application does the arithmetic first and the model
only rewords the verified result, so a slow model delays the wording, never the
figures.

Renderer timings include module load on the first scale measured, so the PDF and
Excel figures at the smallest scale are inflated by roughly 300-700 ms of one-off
import cost. Both are independent of transaction count -- they render the already
computed report payload -- so the later, warm numbers are the representative ones.

## Results

| Operation | 50,000 txns | 100,000 txns | 250,000 txns |
| --- | ---: | ---: | ---: |
| Initial import | 6.39 s | 14.75 s | 33.62 s |
| Initial import, per 1,000 transactions | 128 ms | 148 ms | 134 ms |
| Incremental sync | 267 ms | 555 ms | 1.50 s |
| Vendor spend aggregation | 16 ms | 30 ms | 109 ms |
| Dashboard load | 8 ms | 2 ms | 10 ms |
| Drill-down | 29 ms | 62 ms | 184 ms |
| Report build | 117 ms | 240 ms | 535 ms |
| PDF render | 708 ms | 307 ms | 324 ms |
| Excel render | 269 ms | 24 ms | 25 ms |
| Chat: month summary | 9 ms | 5 ms | 6 ms |
| Chat: profit bridge | 7 ms | 4 ms | 6 ms |
| Chat: vendor ranking | 4 ms | 3 ms | 3 ms |

### What each row measures

- **Initial import** — 50,000 transactions
- **Initial import, per 1,000 transactions** — derived from the run above
- **Incremental sync** — re-import of one month (2,083 transactions, all already stored)
- **Vendor spend aggregation** — group and rank one month of transactions by vendor
- **Dashboard load** — 24 months of metrics, the current month and its category totals
- **Drill-down** — transactions behind one category for one month, capped at 300
- **Report build** — the full deterministic monthly report payload
- **PDF render** — the complete monthly PDF
- **Excel render** — the complete monthly workbook
- **Chat: month summary** — deterministic resolution, no model call
- **Chat: profit bridge** — the most expensive question the resolver answers
- **Chat: vendor ranking** — ranks vendors from stored spend
